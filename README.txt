نظام أمانة السر - ثانوية أبي بكر الصديق رضي الله عنه الشرعية للبنين
حزمة GitHub Pages + PWA النهائية

الملفات:
1) index.html              ملف البرنامج الرئيسي
2) manifest.webmanifest    إعدادات تثبيت التطبيق
3) sw.js                   تشغيل التطبيق دون إنترنت بعد أول زيارة
4) icon.svg                أيقونة التطبيق
5) README.txt              هذا الدليل

طريقة النشر على GitHub:
1. أنشئ Repository جديد.
2. ارفع جميع الملفات الموجودة في هذا المجلد إلى المجلد الرئيسي Repository root.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch.
5. اختر Branch: main ثم Folder: /(root).
6. اضغط Save وانتظر رابط GitHub Pages.
7. افتح الرابط مرة واحدة أثناء وجود الإنترنت.
8. من متصفح الهاتف اختر تثبيت التطبيق / Install app أو Add to Home screen.

مهم:
- لا تغيّر أسماء الملفات.
- يجب أن تكون الملفات الأربعة الأساسية في نفس المجلد.
- التطبيق يعمل محليًا ويحفظ البيانات على الجهاز.
- النسخة الاحتياطية مهمة قبل تغيير الهاتف أو حذف بيانات المتصفح.
- الشعار المخصص يمكن إضافته من الإعدادات داخل البرنامج.
